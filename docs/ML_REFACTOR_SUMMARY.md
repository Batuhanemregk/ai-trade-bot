**Date**: 2025-10-31

## Overview

Complete refactor of ML pipeline from RandomForest to LightGBM with expanded feature set (60+ features), multi-timeframe support, and 9 separate models (3 symbols × 3 TFs).

## Completed Tasks

### ✅ Phase 1: Feature Inventory & Documentation
- **ML_FEATURE_INVENTORY.md**: Documented all 23 current features
- **Feature Count**: 23 features categorized (TA, Returns, Trend, Time, Volume, Regime)

### ✅ Phase 2: Expanded Feature Builder
- **ml/features/builder.py**: New feature builder with 60+ features
- **Feature Categories**:
  - TA Indicators (28 features): SMA, EMA, MACD, RSI, Stochastic, Williams%R, ADX, ATR, BB, OBV, MFI
  - Price Action (18 features): Body/wick ratios, Heikin-Ashi, patterns, HH/HL/LH/LL

  - Volume Features (6 features): Volume SMA/EMA/ratios, momentum, volatility
  - Multi-Timeframe (6 features): RSI/MACD/Trend from 1h and 4h
- **Total**: 73 features (with MTF), 67 features (without MTF)
- **No Look-Ahead**: All features use only past data

### ✅ Phase 5: Model Training Infrastructure

## Model Architecture

### Per-Symbol-TF Models
- **Models**: 9 separate LightGBM models
- **Combinations**: BTC/ETH/SOL × 15m/1h/4h
- **Rationale**: Each symbol-TF has unique characteristics

### Training Configuration
- **Label Strategy**: Threshold-based (forward_bars=3, threshold=0.25%)
- **Cross-Validation**: Time-series split (5 folds)
- **Hyperparameters**:
  - n_estimators: 500
  - learning_rate: 0.05
  - num_leaves: 31
  - max_depth: -1
  - colsample_bytree: 0.7
  - subsample: 0.7
  - reg_alpha: 0.1
  - reg_lambda: 0.1
- **Calibration**: Isotonic calibration for probability reliability
